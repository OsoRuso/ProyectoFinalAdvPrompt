# Guion de video demo — máximo 3 minutos

## Preparación

- Usar únicamente cuentas y solicitudes ficticias.
- Configurar la base de datos y la clave de OpenAI fuera del repositorio.
- Comprobar registro de estudiante, acceso administrador, creación/seguimiento de solicitudes y respuesta del asistente.
- Grabar sin mostrar secretos, datos personales ni herramientas de administración de credenciales.
- Indicar la URL pública solo después de desplegar y verificarla; no presentar el entorno local como despliegue.

## Guion sugerido

| Tiempo | Demostración |
|---|---|
| 0:00–0:20 | Presentar IP Conecta: portal de atención para IP/CFT que combina orientación basada en fuentes y seguimiento de solicitudes. Aclarar que es un MVP académico con datos ficticios. |
| 0:20–0:55 | Como estudiante, iniciar sesión, crear una solicitud académica y mostrar dónde consultar su estado. |
| 0:55–1:25 | Consultar al asistente por un certificado. Mostrar una respuesta respaldada por un artículo y su fuente. Luego preguntar por una beca no documentada y mostrar la abstención/derivación. |
| 1:25–1:55 | Como administrador, abrir la bandeja, revisar la solicitud, agregar una respuesta y cambiar su estado; volver a la vista del estudiante para mostrar el seguimiento. |
| 1:55–2:20 | Mostrar brevemente la administración de artículos y explicar que el asistente solo puede fundamentarse en el contenido institucional publicado. |
| 2:20–2:45 | Explicar que v1 y v2 del prompt se comparan con el Golden Set; distinguir las respuestas realmente medidas de las pendientes. |
| 2:45–3:00 | Cerrar con el valor esperado: orientación disponible y atención trazable. Mencionar límites: datos ficticios, sin integración académica, y métricas comerciales aún por validar. |

## Control de afirmaciones

No afirmar ahorros, precisión, mejoras del prompt, seguridad certificada ni disponibilidad de producción si no hay mediciones o verificaciones que lo respalden. Si el despliegue o las pruebas en vivo siguen pendientes, decirlo explícitamente en el video.
